    H100 performance

    Infinity V3 alpha.19 on one H100 80 GB, with eight CPU threads and 64 GiB RAM. End-to-end HTTP throughput, request latency and startup time for text embeddings, reranking, image embeddings and decision requests. Measured October 25–26, 2026; production latency depends on the traffic mix.

    Text embeddings

    FP16 on one H100 with the same server CPU allocation. Throughput is input tokens/s at concurrency 32. Latency is the fastest observed 8-token request; startup is the median of three fresh starts with local weights, excluding downloads.     Measurement notes

    Throughput uses two five-second windows after warmup. Reranking, image and decision rows report the best median across tested concurrency levels. Text embeddings use JSON float outputs, a 16K batch-token budget and no Radix MLP; DeBERTa uses 8K. Startup storage caches were uncontrolled. Measurement data contains mixed-length workloads, individual runs, checkpoint names, image identity and numerical checks.

    Accuracy: not evaluated on a task benchmark. † Qwen3-VL BF16 failed one numerical parity check (0.998545 cosine; threshold 0.999). Elephant passed the sampled choice checks but showed probability differences up to 1.87 percentage points. Validation details and reference outputs are described in the data file.
