# Infinity ♾️

Infinity serves embeddings, reranking, classification and decision models.
Choose the documentation for your server:

- **[Infinity v3](v3/README.md)**: the native Rust and LibTorch server.
  Start with the [quickstart](v3/quickstart.md) or browse
  [supported models](v3/docs/supported-models.md).
- **[Python / v2](deploy.md)**: the existing Python server, including
  [CLI](cli_v2.md), [Python engine](python_engine.md) and
  [client](client_infinity.md) documentation.

V3 is the direction for future development. Both generations remain documented
here while users migrate; choose the matching section when configuring a server
or integrating its API.
